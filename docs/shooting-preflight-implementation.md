# 拍前检查实施记录

日期：2026-10-06。对应要求：[拍前检查功能规划](shooting-preflight-plan.md)。

## 已实现

- 文案列表右上角增加“拍前检查”，工作区菜单提供入口，快捷键为 ⌘⇧P。
- 项目保存主、辅设备 ID，可交换角色，禁止指向同一设备；设备改名不改变身份。
- 读取清理后主设备 A-roll，使用系统本机中文语音识别提取词级时间。可以导入当前视频对应的 SRT，校验字幕时间不超出视频长度。原文只参与定位，不被转录替换。
- 唯一匹配、边界可靠、置信度足够的行显示实际时长；其余显示“估算／需确认”。用户可以明确保留估算，系统不会改称实际时间。句间停顿计入画面时长。
- 行内时长按钮打开检查面板，可播放对应主设备片段；没有可靠定位时不按估算秒数播放。时间线按实际时长和明确标注的估算排列。
- 两类提醒分别开关、调整阈值；设备切换只打断同设备提醒，B-roll 打断两类提醒。重叠疑点合并成卡片，保留每条规则自己的范围和时长。连续 A-roll 阈值与已有节奏设置同步。
- 独立的 DeepSeek 内容检查任务、提示词和 JSON 协议，沿用现有连接。仅发送文本和现有安排，不发送视频。候选保留一句画面建议，不写入备注或改写文案。
- 严格验证行 ID、逐字引用、唯一位置、重叠与快照。确认后复用现有拆分迁移，保留未涉及范围的设置、备注和素材绑定；一次撤销恢复整个操作。无明确制作方式时系统安排使用“未确定”，人工切换默认值保持原行为。
- 保存“保留口播／确认保留”结论，相同内容与安排可复用；无关段落变化不清除局部保留结论。过期内容候选不能应用，主动重新检查后才可继续确认。
- 汇总待检查、有待确认项和检查完成。未确定制作方式、需确认时间和未处理疑点计入剩余数量，始终允许拍摄。
- 实体清单同时收集实拍 B-roll 与辅设备 A-roll，其他制作方式使用现有准备筛选。无需绑定文件即可完成任务，支持撤销。
- 可选导入只包含一句话的辅设备实录片段，保存项目副本并使用整个片段的实际长度重新计算；原主设备时间继续用于参考播放。未导入的辅设备时长明确标为待定。导入同时标记已准备，可撤销，无强制质检。
- 项目 JSON 与本机偏好保存时间、设备角色、候选、结论及辅设备记录，旧项目缺少新字段时使用默认值。清单发生变化时显示任务新增／减少数量。

## 已执行验证

- `Tests/run-preflight-tests.sh`：原文时间边界、重复转录、低置信度、字幕重叠、句间停顿、两类节奏、重叠疑点合并、AI 输出协议离线模拟、短句候选、错误引用与过期快照拒绝、拆分文字完整性、一次撤销／重做、设备与备注继承、默认制作方式、实体任务、完成状态、项目恢复，以及辅设备实录时长更新。
- 原有六组回归通过：节奏、动画、拍摄设备、制作方式、筛选、时间线。时间线包含 18 项检查和 400 个固定缩放滚动位置。
- 全 Xcode、独立 DerivedData 的 Debug 构建成功，未进行发布打包。
- 在独立应用标识、独立测试项目中实际点击验证：SRT 导入后两行分别显示 6 秒、2 秒；合并提醒显示实际 8 秒；播放器正常播放测试视频并在指定范围结束；换辅设备后分别显示同设备 6 秒／连续 A-roll 8 秒；调整同设备阈值后只剩连续 A-roll。
- 实际界面验证“未确定”卡片、选择实拍后立即更新、实拍与辅设备同时进入清单、辅设备任务完成后隐藏、一次撤销恢复，以及导入辅设备测试视频后显示实录 8 秒并标为已完成。
- 完整结束测试进程后重新打开，确认项目目录授权、主设备时间、B-roll 制作方式和辅设备选择恢复。
- 修复实际点击发现的检查列表视图复用问题，改为稳定的非惰性卡片容器；保存数据与显示同步。

## 尚未证明的效果

系统本机中文语音识别在真实长口播上的识别质量，以及在线 DeepSeek 对真实文案的候选质量，尚未使用实际素材验收。当前已验证独立网络协议与拒绝不安全引用的程序逻辑；界面播放使用生成的测试图案视频，不能证明口播听感、语音定位准确性或创作判断质量。

这项文本检查不会观看素材，也不承诺发现全部创作需要。用户确认的安排决定检查是否完成。
