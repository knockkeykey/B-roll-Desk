# B-roll Desk

B-roll Desk（App 名称：B-roll配对台）是一个仅提供原生 macOS App 的本地辅助工具，用来整理口播文案中的 A-roll 与 B-roll、列出待拍摄或待制作的画面，并把完成的 B-roll 素材绑定到对应台词。准备好剪辑项目文件夹后，可以把文件夹和 App 提供的提示词交给支持 ChatCut 剪辑插件的 AI，辅助完成可继续编辑的时间线粗剪。

这里的 **A-roll** 指对着镜头讲述的主画面；**B-roll** 指穿插进来补充说明的画面，可以是实拍、动画、AI 生成视频、图片加动效、现成素材或屏幕录制。

## 工作流程

### 1. 整理文案并列出 B-roll 任务

1. 启动 App，选择一个空的剪辑项目文件夹。App 会在其中创建 `A-roll/` 和 `B-roll/`。
2. 打开“编辑 / 导入文案”，粘贴文案，或导入 `.txt` / `.md` 文件；可以按换行或按句末标点拆分条目。
3. 文案条目默认作为 A-roll。点条目上的类型标记，可切换为 B-roll。
4. 为 B-roll 条目选择制作方式，也可以写备注。使用“待准备”筛选，就能集中查看要拍摄或制作的画面。
5. 每完成一项，就把它标记为“素材就绪”。

条目可双击修改；编辑时在句末按回车可拆成两条，在条目开头按 Backspace 可与上一条合并。确认文案后，内容会保存到 `A-roll/正确文案.txt`，后续编辑也会同步更新这份文件。

如果已经录好口播，可以把一个 A-roll 视频拖到 App 的 A-roll 区域，或点击“上传 A-roll”选择视频。App 会把副本保存为 `A-roll/A-roll.<原扩展名>`，保留原视频文件。

### 2. 绑定已完成的 B-roll 素材

1. 将完成的 B-roll 素材统一放进一个或多个素材来源目录。
2. 在素材列表中添加这些目录。列表会合并显示所选目录下的视频和图片；目录也可以加入常用目录，供其他项目使用。
3. 可填写命名前缀，例如 `第15期`；留空时文件名直接从 `BR001` 编号开始。
4. 将素材从右侧列表拖到左侧对应的 B-roll 文案条目。同一条文案可以绑定多个素材。

绑定时 App 会把素材**复制**到当前项目的 `B-roll/`，原始素材不会被移动或重命名。归档文件名示例：

```text
第15期_BR001_提到葫芦娃时出现对应画面.mp4
第15期_BR002_提到孙悟空时出现对应画面_02.jpg
```

编号用于区分和核对素材，不代表时间码。B-roll 视频在对照表中的默认音频设置为静音。

### 3. 交给 AI 做时间线粗剪

确认 B-roll 绑定后，点击“复制提示词”，再把提示词和整个剪辑项目文件夹一起提供给支持 ChatCut 剪辑插件的 AI。提示词要求 AI 根据 `A-roll/正确文案.txt` 剪辑口播，并按 `B-roll/broll-for-codex.json` 把指定素材放到对应台词上方；完成后检查并保存可继续编辑的 ChatCut 时间线。

配对台负责整理文案、素材和映射关系；实际剪辑由具备相应 ChatCut 工具能力的 AI 完成。

## 剪辑项目文件夹

完成准备后，文件夹大致如下：

```text
剪辑项目/
├── A-roll/
│   ├── A-roll.mov                 # 上传后的视频副本，扩展名随原文件
│   └── 正确文案.txt                # 确认后的文案
└── B-roll/
    ├── 第15期_BR001_文案短句.mp4   # 已绑定素材的副本
    ├── broll-for-codex.json        # 给 AI 使用的精简素材映射
    ├── broll-manifest.json         # 完整绑定记录及默认音频设置
    └── project-settings.json       # 项目设置、文案分类、准备状态及来源目录
```

`broll-for-codex.json` 只包含文案和归档文件名，格式如下：

```json
{
  "placements": [
    {
      "text": "对应的完整文案",
      "files": ["第15期_BR001_文案短句.mp4", "第15期_BR001_文案短句_02.jpg"]
    }
  ]
}
```

## 保存与文件权限

- App 通过 macOS 文件选择面板获得素材来源目录和剪辑项目文件夹的读写权限，并用安全作用域书签记住已选目录。
- 文案分类、每条备注、B-roll 制作方式和准备状态、命名前缀、素材绑定及素材来源目录会保存到项目设置中。重新打开项目文件夹时，App 会恢复该项目的状态。
- 如果素材来源目录不可用，重新连接该目录后即可继续使用。
- 取消某项绑定会删除项目 `B-roll/` 中对应的复制文件，并更新对照表；素材来源目录里的原件会保留。
- 手动修改 JSON 文件后，重新在 App 中保存对照表可能会覆盖这些修改；项目设置以 App 保存的状态为准。

## 运行要求

- 本项目只通过 macOS App 运行。
- macOS 14 或更新版本。
- 使用 Xcode 16.4 或更新版本打开 `B-roll Desk.xcodeproj`，运行 `B-roll Desk` scheme。
- 项目的 SwiftUI 源码位于 `BRollDeskApp/`；文件读写使用用户选择的目录权限。
